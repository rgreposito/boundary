# Security

Boundary is an experimental reference, not a hardened hosted service. Do not
connect it to production side effects without implementing the prerequisites in
[the threat model](docs/threat-model.md).

For a vulnerability, use the maintainer contact on the GitHub profile. Do not
post credentials, private data or an active exploit against another system in a
public issue. Include the violated invariant and a minimal synthetic reproducer.

No response-time guarantee or supported production release is offered.
